# StrayerBlox

**StrayerBlox** is an open-source Roblox bootstrapper and launcher developed by **Kervect**.

The project aims to provide a lightweight, transparent, and customizable way to launch and manage Roblox while keeping the software focused on security, simplicity, and user control.

## ✨ Features

> StrayerBlox is currently in early development.

Planned features include:

* 🚀 Roblox launcher
* 🔍 Roblox installation detection
* ⚙️ User configuration
* 🔄 Update detection
* 🎨 Customizable launcher interface
* 🧩 Extensible architecture
* 🔓 Fully open-source code

## 🛡️ Philosophy

StrayerBlox is designed to remain transparent and safe.

It does **not** aim to modify the Roblox client, inject code, bypass security systems, or provide unfair advantages.

## 🧑‍💻 Development

StrayerBlox is developed using **C# and .NET**.
